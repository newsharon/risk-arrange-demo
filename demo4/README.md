# Demo 4 — 재물 언더라이팅: 소재지 조회 / 누적조회 (Dash)

Demo 3을 기반으로, **재물 언더라이팅 부서 요구사항**을 반영해 새 페이지("재물 소재지 조회", `/property`)를
추가한 버전입니다. Demo 3의 다른 페이지(대시보드/태풍/해상/캘린더)는 그대로 유지됩니다.

## 추가된 기능 — 재물 소재지 조회 (`/property`)

재물 언더라이팅팀이 전달한 요구사항을 기준으로 구현했습니다.

1. **소재지/물건 검색 + 지도 조회**
   - 지도에 전국 공장/물건을 점으로 표시 (보종별 색상 구분, 당사계약 없는 물건은 회색)
   - 검색창에 소재지/건물명을 입력하면 해당 물건으로 지도 이동 및 상세 조회
   - 지도에서 점을 클릭해도 동일하게 상세 조회 가능
2. **물건정보 / 계약정보 상세**
   - 당사계약이 있으면 계약정보(보종, 가입금액, PML, 당사보험료, 만기 등) 표시
   - 당사계약이 없으면 화보협 스타일 물건정보(구조, 용도, 연면적, 소방시설, 위험등급)만 표시
3. **누적조회 배너**
   - 반경(250m / 500m / 1000m, 선택 가능)을 지정하면 해당 소재지 주변 물건·계약 리스트업
   - 누적 가입금액, 누적 PML, 누적 계약건수, 누적 당사보험료 등 요약 KPI 출력
   - 물건별 특이사항(화재이력, 인접 위험요소 등) 표시
4. **필터**
   - 보종(LOB)별 필터 버튼, 계약자(정책보유자)별 드롭다운 필터

> 데이터는 Demo 1~3에서 사용하는 전국 25개 공장 더미 데이터(`DUMMY_FACTORIES`)를 기반으로,
> 인근 위성 물건 20곳을 추가해 누적조회가 의미 있게 동작하도록 구성한 더미 데이터입니다.
> (`PR-XXXX` 형식의 가상 물건 ID, 화보협 자료를 흉내낸 물건정보 포함)

## 실행

```bash
python -m pip install -r requirements.txt
python dash_app.py
```

브라우저에서 http://127.0.0.1:8050 접속 후 좌측 메뉴의 "재물 소재지 조회"를 클릭하세요.
